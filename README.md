# Data-Mining-Project---Real-estate
This project applied data mining techniques to 1,393 Tunisian real estate listings to build and evaluate price prediction models. 
 The data preparation pipeline included median imputation,
domain-knowledge outlier removal, three engineered features, ordinal and one-hot encoding, a
strati ed 70/15/15 split, and leakage-free StandardScaler normalisation.
Three regression models and two classi ers were benchmarked on a held-out validation set, with
the best model evaluated once on the test set.
